| Being a boot target of Schwung's boot selector: the registry in `/data/UserData/boot-targets`, `boot.json`, the entry script's contract (run as `ableton`, end on TERM, hand the Move on when done), module.json's `boot_target` | `module/boot-entry.sh`, `tools/install-schwung-tool.sh`, written after reading [Schwung](https://github.com/charlesvestal/schwung)'s `docs/BOOT_TARGETS.md`, `src/shim-entrypoint.sh`, `src/host/boot_target_lib.sh` and `src/launch-standalone.sh` (MIT); no code copied | references only |
| Schwung's screen reader speech: the segment `/schwung-tts` (its request seqlock, the speak hand-off, the audio ring) and how the sidecar `schwung-tts` is started | `src/move/schwung_tts.h`, declared field for field from [Schwung](https://github.com/charlesvestal/schwung)'s `src/host/tts_shm.h`; `src/move/speech.cpp` written after reading its `src/host/tts_client.c`, `tts_sidecar.c` and `shadow_process.c` (MIT, Copyright (c) 2025-2026 Charles Vestal); no code copied. The sidecar and its eSpeak NG are Schwung's on the Move, run as their own program, never shipped or linked | MIT; the interface a client is written against |
| A standalone tool's own privileged helper, installed by Schwung's `schwung-heal` from `bin/heal.new` | `src/boot/heal.c`, `module/standalone`, written after reading [Schwung](https://github.com/charlesvestal/schwung)'s `docs/MODULES.md` ("a privileged helper of their own") and `src/schwung-heal.c` (MIT); no code copied | references only |
| Schwung's module ABI: the host table, the v2 plug-in table, `move_plugin_init_v2`, `move_info_t` for `schwung_move_info()` | `src/app/schwung_api.h`, `src/app/module_host.cpp`, `tests/fake_module/dsp.c`, declared field for field from [Schwung](https://github.com/charlesvestal/schwung)'s `src/host/plugin_api_v1.h` and `src/host/move_info.h` (MIT, Copyright (c) 2025-2026 Charles Vestal) | MIT; the interface a module is built against |
| How a host outside Schwung serves its modules: a complete host table, `schwung_move_info()` exported from the process, create and destroy off the audio thread, libraries never closed | `src/app/module_host.cpp`, written after reading [Movy](https://github.com/DimaDake/schwung-movy)'s `host/vtable.c`, `engine/crates/movy-dsp/src/host_vtable.rs`, `move_info.rs` and `docs/module-state-support.md` (MIT); no code copied | references only |
| Schwung's page controller (`shared/param_pages`: the page planner, its controller and input), which decides a module's pages and menus for Melodee to draw in its own look | run by `src/app/schwung_pages/host.js` (`src/app/schwung_pages.*`), imported at run time from the Schwung installed on the Move (`/data/UserData/schwung/shared`, MIT, Copyright (c) 2025-2026 Charles Vestal and contributors); never shipped or copied here (the tests fetch the Move's release, v1.9.4, into `build/deps`). The seam follows Schwung's own consumer, `src/shadow/shadow_ui_param_pages.mjs`; its footer verbs (`footerHints`) and tick duties are written again in `host.js` after reading it, and `src/app/user_presets.*` and `screens/module_help.cpp` read and write Schwung's user preset files and `help.json` as `shadow_ui_presets.mjs` and its help viewer do; no code copied | MIT; run, not copied |
| [QuickJS](https://bellard.org/quickjs/) 2025-04-26 (Fabrice Bellard, Charlie Gordon) | fetched to `build/deps/quickjs` by `tools/dependencies.py` (pinned by its SHA-256; the same release, file for file, as Schwung's `libs/quickjs`), linked into the binary; its licence in `licenses/QuickJS-LICENSE.txt` | MIT |
| Schwung's canvas page contract: `canvas_overlay` and its hooks, the `ctx` a page draws and reads through, `handleBack`'s true, the entering push kept by the host; its bitmap font's file format (a strip of cells, a `.dat` list) | `src/app/canvas_page.*`, written from Schwung's `docs/CANVAS_PAGES.md`, `src/host/js_display.c` and the pages Radio Garden and Webstream ship (MIT, Charles Vestal); no code copied. | Melodee's wordmark | drawn into the web page's bundle by melodee-sample's own `tools/web_bundle.py` from its `docs/images/melodee-wordmark.png` | Melodee's, Kerem Kiliç (Ellic Studio) |

Not part of this repository and never shipped: `jack_move.so` (the Move's
